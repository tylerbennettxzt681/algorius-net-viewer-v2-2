## Overview

Algorius Net Viewer gives Windows administrators a visual way to examine devices, connections, and current network health. Discovery, topology visualization, and monitoring are brought together in a single desktop workspace, reducing the need to switch between separate scanning, mapping, and reporting utilities.

The application is suitable for maintaining a visual inventory of network assets, checking device status, and observing infrastructure changes over time. It can use SNMP, ARP, ping, and port scanning workflows to locate hosts, test accessibility, and record network conditions from different perspectives.

## Typical Workflow

Use the following sequence as a starting point for network mapping and monitoring:

1. Run discovery against the network segment you need to examine.
2. Inspect the resulting topology graph to see the detected device relationships.
3. Open individual device records for profile details, inventory data, and current status.
4. Apply ping, SNMP, ARP, or port scan checks when host validation is required.
5. Add alert rules for devices or state changes that deserve attention.
6. Export the collected information as a report or shareable snapshot.

For ongoing observation, select the interface associated with the network of interest and return to the topology view as devices appear, disappear, or change state.
